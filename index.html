Cargar la planilla Gantt de la semana

Seleccione el archivo .xlsx semanal (el mismo que se envía cada semana). Se lee la hoja Gantt Control directamente en su navegador: el archivo no se sube a ningún servidor.

Publicar la actualización en GitHub (para que todos la vean)

  1. Cargue arriba el Gantt de la semana y revise que el dashboard se vea bien.
  2. Presione Descargar avance.json.
  3. En GitHub, entre al repositorio → Add file → Upload files (en la página principal del repositorio, no dentro de una carpeta).
  4. Arrastre el archivo avance.json (reemplaza al anterior) y presione Commit changes.
  5. En 1 a 2 minutos la página publicada muestra la nueva semana.

El Gantt contiene toda la historia semanal, por lo que basta con subir el archivo de la última semana; el selector "Semana de control" permite revisar semanas anteriores.
